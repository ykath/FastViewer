# LightPage 1.6.5 Windows 发布说明

- Markdown 流程图默认使用精致排版。普通节点为圆角卡片，判断节点使用虚线轮廓，分支标签采用胶囊样式，连线使用圆角折线。
- 在「设置 → 流程图样式」切换到「原始」，可按标准 Mermaid 形状和布局查看。
- 流程图不再套用普通代码块的深色背景。浅色与深色主题、桌面放大查看、图片与富文本复制、打印及图片导出均使用阅读页的图表。
- 本地构建提供 Windows x64 便携程序与 NSIS 安装包。两个文件沿用未签名构建，Windows 可能显示 SmartScreen 提示。

## 技术调研与实现

在本机 Codex 安装包 OpenAI.Codex_26.1106.6628.0 中，流程图预览模块包含 Mermaid 路径，使用基于 ELK layered 的布局适配器。它会在布局前处理矩形与判断节点，再为分支标签、线条和箭头应用主题。安装包内也有受开关控制的 Pele 路径。静态检查可确认两条实现存在，无法确定截图当时启用的路径或其他版本的行为。

LightPage 旧版锁定 Mermaid 11.17.2，但未注册 ELK。使用真实报告还复现了另一处问题：图表组件嵌在普通代码块中，继承了深色背景与外边距。1.6.5 直接从 Markdown 语法节点识别 Mermaid 代码块，同一入口覆盖普通文档与渐进渲染文档。

1.6.5 保留 Mermaid 11.17.2，按需加载兼容的 @mermaid-js/layout-elk 0.2.3。通过插件的布局阶段与 Mermaid 的测量、绘制接口，先测量节点和标签，再进行 ELK 布局。主题规则随 SVG 保存，适用于放大、打印与复制。显式配置布局或样式的图表由标准 Mermaid 路径处理，避免应用主题覆盖作者配置。非流程图沿用标准渲染。精致布局异常时会回退至原始样式，原始渲染也失败时显示源码。文档内配置不能更改安全级别或启用 HTML 标签。

打开「设置 → 流程图样式」即可切换排版。原有设置缺少此选项时默认显示「精致」。Android 版本字段同步为 1.6.5 / 15，本次交付平台为 Windows。

参考资料：[Mermaid 布局](https://mermaid.js.org/config/layouts.html) · [Mermaid 主题](https://mermaid.js.org/config/theming.html)
