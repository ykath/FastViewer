# 轻页使用帮助

## 打开文件

- 在首页选择 Markdown、HTML、ZIP 或 RAR 文件，也可从文件管理器、聊天或邮件附件中用“轻页”打开。
- “粘贴打开”会识别 Markdown 与 HTML；HTML 默认在严格沙盒中显示。
- 10 MB 及以上文件默认使用源码模式，确认设备性能足够后可切换到阅读视图。

## HTML 安全与资源

- 脚本、表单、弹窗相互独立，默认全部关闭。
- 远程图片、样式和字体默认阻止，可按文件仅允许本次加载。
- 独立 HTML 的相对图片或 CSS，可在“HTML 权限”中授权所在目录；资源会复制到 App 私有目录。
- 外部链接始终由轻页显示确认提示后才会打开。

## Markdown 本地图片

- Windows 版会以 Markdown 文件所在目录为基准加载相对图片，例如 `![截图](images/demo.png)`。
- 为避免 Markdown 越权读取其他目录，只允许当前文档同目录及其子目录中的 PNG、JPEG、GIF 和 WebP 图片。
- 单张图片最大 20 MB，每篇文档最多加载 64 张、合计不超过 64 MB；超出限制的图片会显示加载失败提示。

## Windows URL 导入

- 在 Windows 首页选择“打开 URL”，或按 `Ctrl+Shift+O`。首版只接受 HTTP/HTTPS 地址，Android 与 Web 不显示该入口。
- 轻页会依次尝试系统中的用户级/系统级 Chrome 和 Microsoft Edge，并使用独立的 LightPage profile；不需要安装 Node.js 或 Bun，也不会读取日常浏览器 profile。
- 默认在后台完成加载、抽取、图片下载、校验和保存。遇到登录、CAPTCHA 或页面质量异常时，可选择“打开浏览器重试”，操作完成后点击“我已完成，继续”。交互等待最长 10 分钟，也可随时取消。
- 快照保存到“文档/LightPage/url-to-markdown/域名/文章名/文章名.md”，图片放在同目录的 `imgs/` 中；重复导入生成带时间戳的新快照。
- 支持通用网页、X/Twitter、YouTube 字幕和 Hacker News。YouTube 没有字幕时仍会保留标题、描述等可用内容并给出警告；网站改版、反爬或网络限制可能导致内容不完整。
- 删除文件库记录不会删除“文档”目录中的 URL 快照。若不再需要，请在资源管理器中自行删除对应文章目录。

## 文件与导出

- “最近”是访问记录；“文件库”表示正文和原始文件已持久保存到本机 App 目录。
- 删除记录会同时清理正文、归档资源和授权目录缓存；收藏或文件库中的记录不会被“清理未收藏记录”删除。
- Android 可生成并分享真实 PDF；图片支持当前区域、全文和分页长图；分享原文件会使用原始字节。

## 常见问题

- 编码错误：在文件菜单中打开“编码设置”，尝试 GBK、UTF-16 或 Latin-1。
- 压缩包无法打开：加密包、损坏包或超过安全限额的内容会被拒绝并清理临时目录。
- 目录或搜索不可用：启用 HTML 脚本后页面使用隔离来源运行，父页面无法直接读取其 DOM。
- URL 导入提示浏览器缺失：请安装受支持的 Chrome 或 Microsoft Edge，并重新发起导入。
- URL 导入提示网络超时或抽取失败：检查网络和页面能否在浏览器中访问；如页面需要登录，使用交互重试。
