# 《轻页》下一阶段产品功能规划（v1.6）

版本：v1.6 规划稿  
日期：2026-09-26  
规划基线：LightPage v1.5.3（源码 `package.json` 1.5.3，Android `versionCode 9`）  
适用平台：Android、Windows 10/11 x64  
建议周期：8 周（按 1 名全栈开发 + AI 辅助的实际投入估算）

---

## 1. 结论

轻页已经完成“本地优先的 Markdown / HTML 阅读器”的完整闭环：打开、渲染、目录、搜索、排版、收藏、导出、分享、安全沙箱在两端均可用；Android 的移动闭环（外部打开队列、文档包、批注、分享卡片、沉浸阅读、折叠屏）和 Windows 的单文件桌面阅读（同目录切换、文件监听、命令面板、窗口集成）也已基本到位。

当前的主要问题不再是“缺基础功能”，而是：

1. **双端能力不对称**：批注、书签、ZIP 文档包只在 Android 可用，Windows 数据底座已兼容但没有界面。
2. **跨文档能力缺失**：只能在单篇文档内搜索，文件库和固定目录无法全文检索。
3. **发布可信度不足**：安装包仍未正式签名，没有应用内更新提示，README 和使用指南版本滞后。
4. **工程可维护性下降**：`App.tsx` 约 196 KB，1.5.3 发布后又修复了目录跳转回归，说明主组件修改的回归风险在上升。

因此 v1.6 的主题定为：**“双端对齐 + 资料检索 + 可信发布”**。不新增编辑、云同步和多标签，继续保持“轻”。

## 3. v1.6 产品目标

### 3.1 目标

1. **双端对齐**：Windows 补齐批注 / 书签 / 高亮和 ZIP 文档包，两端核心阅读产物一致。
2. **资料检索**：支持文件库与 Windows 固定目录的本地全文搜索。
3. **可信发布**：正式签名、应用内更新提示、对外文档与版本一致。
4. **可维护**：拆分 `App.tsx`，建立目录 / 锚点 / 视频等高风险功能的回归用例。

### 3.2 非目标

- 不做 Markdown / HTML 编辑器（仅允许批注、书签等轻量阅读产物）。
- 不做账号、云同步、团队协作。
- 不恢复 Windows 多标签、并排阅读。
- 不默认上传正文，不接入需要上传正文的在线 AI 能力。
- 不扩大 HTML 默认权限。

## 4. 功能规划

### 4.1 P0：v1.6.0 发布承诺

#### F1 Windows 批注、书签与高亮

数据模型、IndexedDB 存储、重定位算法和浮动选区工具栏两端已经共用。v1.6 补齐桌面体验，不重做数据层：

- 高亮从单色改为 3 色；`DocumentAnnotation` 增加可选 `color`，旧数据使用默认色。
- 左侧阅读栏新增“批注”视图（与“章节 / 当前目录”并列），支持跳转、编辑、删除和筛选。
- 快捷键：`Ctrl+B` 添加书签，`Ctrl+Shift+H` 高亮当前选区；命令面板同步新增入口。
- 外部修改自动刷新后执行重定位；无法可靠定位的条目标记为“待重新关联”，不静默迁移。
- 支持导出 Markdown 批注摘要。

**验收标准：** 文档未变化时定位成功率 100%；外部保存触发刷新后批注不丢失；Windows 与 Android 的批注摘要格式一致。

#### F2 Windows ZIP 文档包阅读

- 支持打开、拖放 `.zip`，Rust 层流式解压到应用缓存目录，沿用 Android 的条目数、展开总量、压缩比、目录深度和路径穿越限制。
- 复用文档包模型：包内目录、上一篇 / 下一篇、优先打开 README / index、阅读位置恢复、SHA-256 去重。
- 包内相对图片、视频和文档链接可正常解析。
- RAR 暂不在 Windows 支持，给出转换提示。

**验收标准：** 100 MB ZIP 解压期间界面可响应且可取消；超限、加密、损坏包被拒绝且不残留临时文件；删除文档包后缓存同步回收。

#### F3 本地全文搜索

Rust 侧已有 SQLite FTS5 工作区索引（`start_workspace_index` / `search_workspace`），前端尚未调用。首页搜索目前只匹配文件名和已经加载进内存的正文。

- 文件库（两端共用）：IndexedDB 新增 `searchText` store，正文写入时同步建索引，已有文档由后台任务补建；检索在 Worker 中扫描。
- Windows 固定目录：固定或取消固定时接入已有 FTS5 索引，查询结果与文件库合并。
- 首页搜索框升级为全文搜索，结果按“文件库 / 固定目录”分组，展示所在标题、命中片段和命中次数；点击后打开文档并跳到第一处命中。
- 设置中显示索引占用，可重建、清理和关闭。

**验收标准：** 1,000 篇常规文档建索引后查询 P95 ≤ 150 ms；首次索引可取消且不阻塞界面；索引损坏自动重建；关闭该功能后不再扫描。

#### F4 正式签名与发布工程

- Android：本机生成正式 keystore（不入库），`build-apk.bat` 检测到 `FASTVIEWER_KEYSTORE_*` 时构建 `release` APK；README 说明从调试签名版本迁移需卸载重装。
- Windows：1.6.0 继续 `--no-sign`，配置和文档中预留代码签名接入说明。
- CI 质量 Gate 增加版本号一致性检查（`package.json` / `build.gradle` / `Cargo.toml`；`tauri.conf.json` 引用 `package.json`）。

**验收标准：** 配置 keystore 后可产出正式签名 APK，且该签名的后续版本可以覆盖安装。

#### F5 `App.tsx` 拆分与回归加固

这是工程项，不直接面向用户，但决定 v1.6 其余功能能否低风险落地。

- 按职责拆分为：首页 / 文件库、阅读器外壳、文件操作菜单、导出分享、外部打开队列、平台适配等模块；单文件控制在 1,500 行以内。
- 为目录跳转、标题锚点稳定性、视频不重载、相对链接、富文本复制、外部刷新建立端到端回归用例并纳入 Gate。

**验收标准：** 拆分前后现有单元测试与 E2E 全部通过；拆分不改变任何用户可见行为。

#### F6 对外文档同步

- README 更新到 v1.6 的能力、平台差异表和版本历史（补 1.5.3）。
- 使用帮助补充视频、相对链接、批注（Windows）、ZIP（Windows）、全文搜索说明。
- 公众号使用指南另出 v1.6 版本，而不是在 1.1.2 版上修补。

### 4.2 P1：v1.6.x 增强

#### F7 应用内更新提示

- 启动后（默认每 24 小时最多一次）请求 GitHub Releases 最新版本号，有新版本时显示非打断式提示和更新说明链接。
- 只请求版本元数据，不附带任何文档信息；设置中可关闭。

#### F8 网页导入为 Markdown（`url-importer` 收尾）

- 在“粘贴打开”旁新增“从网址导入”：用户显式输入 URL 后，由本地 sidecar 抓取并转换为 Markdown，保存到文件库，保留来源链接。
- 先将 `url-importer` 源码入库、固定 Bun 版本并纳入构建脚本，移除仓库中的二进制缓存；Android 端首版可不支持。
- 界面明确提示“该操作会访问目标网站”，与“正文不上传”的原则区分清楚。

#### F9 纯文本与日志文件一等支持

- `.txt`、`.log` 加入文件选择、Windows 打开方式和 Android Intent 过滤器。
- 纯文本使用等宽 / 正文字体可切换视图，支持搜索、自动换行开关、大文件分块显示。

#### F10 导出独立 HTML

- 将 Markdown 渲染结果导出为单个 HTML 文件（内联样式、图片 Base64、代码高亮、公式），便于发给没有安装轻页的人直接用浏览器查看。
- 视频以链接 / 占位替代，不内联。

#### F11 性能基线进入 CI

- 固定 1 / 5 / 10 / 20 MB 语料，CI 记录打开、首屏、搜索耗时；相对上一版本回退超过 10% 时 Gate 告警。

### 4.3 P2：候选池（视反馈进入 v1.7）

| 功能 | 说明 | 进入条件 |
| --- | --- | --- |
| 文件库标签 / 分组 | 手动标签、按来源（微信、邮件、网页导入）自动分组 | 文件库规模普遍超过 100 篇 |
| Android 朗读（TTS） | 使用系统 TTS 按段朗读，跟随高亮 | 有明确用户反馈 |
| Windows “在新窗口打开” | 以多窗口替代多标签，满足对照阅读 | 对照阅读诉求持续出现 |
| 复制为公众号格式 | 在富文本复制基础上适配公众号编辑器样式 | 富文本复制使用率高 |
| 本地 AI 摘要 | 仅接入本地模型或用户自带 API，默认关闭 | 隐私方案评审通过 |

## 6. 验收指标

### 6.1 产品指标

- Windows 与 Android 在“批注 / 书签 / 高亮 / 文档包 / 全文搜索”五项上能力一致（Windows RAR 除外）。
- 升级后已有批注、收藏、文件库、阅读位置保留率 100%。
- 全部核心任务可离线完成（网页导入、更新检查除外）。

### 6.2 质量与性能指标

- 1,000 篇文档全文搜索 P95 ≤ 150 ms；1 MB 文档内搜索 P95 ≤ 100 ms。
- 10 MB 文档打开、搜索、滚动不崩溃；相对 v1.5.3 的关键耗时或内存回退不超过 10%。
- Gate 覆盖：lint、单元测试、E2E（含目录、锚点、视频、刷新回归）、Android 构建、Rust 测试、版本一致性、签名校验。

### 6.3 保护指标

- ZIP 超限、损坏、加密或路径异常时不写出越界文件，临时目录可回收。
- 全文索引不记录到任何日志或诊断数据中；关闭后可一键清除。
- HTML 默认权限不扩大；网页导入与更新检查是仅有的两处主动联网，且均可关闭或需用户显式触发。

## 7. 风险与决策点

| 风险 / 决策 | 影响 | 建议 |
| --- | --- | --- |
| `App.tsx` 拆分引入回归 | 延误后续功能 | 先补回归用例再拆；按模块逐步提交，每步 Gate 全绿 |
| Windows 代码签名证书成本与获取周期 | F4 可能无法按期完成 | 第 1 周启动采购 / 评估；证书未到位时 F4 降级为“仅 Android 正式签名” |
| Android 调试签名迁移到正式签名 | 用户需卸载重装，可能丢数据 | 提供文件库导出 / 导入或明确备份指引后再切换 |
| 全文索引体积与性能 | 大目录占用磁盘、首次扫描慢 | 只索引受支持文本；显示占用，支持排除目录与暂停 |
| 网页导入与“本地优先”定位的冲突 | 用户误解隐私承诺 | 放入 P1，显式触发、明确提示，默认不自动抓取 |
| 批注在 Windows 外部修改频繁时失效 | 影响信任 | 沿用上下文 + 哈希重定位，失败即标记，不静默迁移 |
