# 轻页隐私说明

轻页默认在设备本地处理文档，不上传文件正文、原始字节、阅读位置或搜索内容。

- 文档正文、原始文件和归档资源保存在 App 私有目录；轻量索引和设置保存在本地应用存储中。
- 本地性能日志仅保留最近 100 条耗时与文件大小等技术指标，不包含正文，且不会自动发送。
- HTML 远程资源默认阻止。只有用户选择“仅本次允许”或启用相应策略时，页面才可能访问远程图片或样式地址。
- Windows URL 导入会访问用户提交的网页和其中的图片，并将成功结果保存到系统“文档/LightPage/url-to-markdown”目录。仅当本地正文抽取未通过质量检查时，公开页面的 URL 可能发送给 Defuddle 公共阅读服务作为回退；不会发送浏览器 profile、Cookie 或已抓取的页面正文。
- URL 导入只使用 LightPage 应用数据目录内的隔离 Chrome/Edge profile，不读取用户日常浏览器 profile。登录状态会跨导入保留，可在设置中通过二次确认精确清除。
- 分享、打开外部链接、目录授权均由用户主动触发并经过系统界面或确认提示。
- 删除普通文档记录时会同步清理对应正文、原始文件、解压目录及授权资源缓存；删除 URL 导入记录不会删除系统“文档”目录中的 Markdown、图片和历史快照。系统分享缓存会在 24 小时后回收。

卸载 App 会由 Android 清除其私有数据。Windows 卸载是否保留隔离网页登录数据取决于卸载选项，建议先在设置中主动清除。Web 版本可通过浏览器站点数据设置清除本地文档和配置。
