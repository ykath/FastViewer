## 更新内容

- Markdown 阅读视图的文件菜单新增“复制富文本”，可将标题、段落、列表、任务状态、引用、表格、代码、链接和图片直接粘贴到 Gmail、Microsoft Word、Foxmail 等软件。
- 剪贴板同时写入 HTML 与纯文本格式；富文本使用中性内联样式，并清理搜索高亮、批注标记和阅读器内部控件。
- Mermaid 流程图会优先转换为内嵌 PNG；转换失败时保留可读源码，普通 Markdown 图片继续按可用地址复制。
- 大型 Markdown 在复制前会临时完成全部渐进式区块渲染，避免遗漏尚未进入视口的末尾内容。
- Android 使用原生 HTML 剪贴板，Windows 使用 WebView2 富文本剪贴板并提供复制事件与纯文本兜底。
- Windows 当前文件在外部保存后会自动同步；原生文件事件与时间戳轮询双重检测兼容常规写入及临时文件替换，并提供文件菜单“重新加载”和 `Ctrl+R` 手动刷新。
- 自动刷新会在读取前后核对文件大小和修改时间，只采用稳定快照；内容变化时整体重建 Markdown 正文，首次瞬时渲染异常会自动恢复，避免搜索或批注高亮产生的 DOM 节点冲突。
- Windows 与 Android 版本统一升级到 1.5.2，Android `versionCode` 更新为 8。
