## 更新内容

- Markdown 阅读视图支持视频播放，兼容图片语法、独立视频链接、Obsidian `![[文件]]`、`<video>` / `<source>`、`@[video]`，以及白名单内的 YouTube / Bilibili 嵌入。
- Windows 本地视频通过 asset 协议按需加载，不再把整段视频读入内存；播放文件本身不会被当成文档外部修改。
- 滚动保存阅读位置时保持视频元素不变，避免播放器反复重新加载。
- 全屏改为应用内覆盖层，避免 WebView2 下点击系统全屏后立即退出。
- Android 压缩包内的视频按对应 MIME 解析；在线 http(s) 地址直接交给播放器。
- 复制富文本时，视频播放器替换为 `[视频]` 或 `[视频：说明]`。
- Windows 与 Android 版本统一升级到 1.5.3，Android `versionCode` 更新为 9。

## 下载说明

- `LightPage_1.5.3_android-debug.apk`：使用 Android 调试证书签名，可直接安装体验；可能无法覆盖使用其他证书签名的旧版本。
- `LightPage_1.5.3_windows-x64-setup.exe`：Windows x64 安装版，推荐普通用户使用。
- `LightPage_1.5.3_windows-x64.exe`：Windows x64 便携版，需要系统已安装 Microsoft Edge WebView2 Runtime。
- Windows 文件尚未进行代码签名，SmartScreen 可能显示安全提示。
