## 更新内容

- Windows 阅读栏增加批注页签，支持跳转、编辑、删除，以及按类型和状态筛选。
- 高亮增加黄、绿、蓝三色；添加批注改为应用内输入。旧批注没有颜色时按黄色显示和导出。
- 快捷键：`Ctrl+B` 添加书签，`Ctrl+Shift+H` 高亮选区，`Ctrl+Shift+B` 打开目录。桌面端可把批注摘要保存为 Markdown。
- Windows 可以导入 ZIP 文档包，重复导入会复用已解压缓存。RAR 会提示先转换为 ZIP。
- 首页改为全文搜索。文件库检索本地正文索引，Windows 固定目录合并工作区全文索引；打开结果后跳到第一处命中。
- 设置页可以查看索引占用，并重建、清理或关闭全文索引。
- Android 发布包改为正式证书签名。Windows 安装包仍使用 `--no-sign`。
- Windows 与 Android 版本统一升级到 1.6.0，Android `versionCode` 更新为 10。

## 下载说明

- `LightPage_1.6.0_android.apk`：使用正式证书签名。已经安装调试证书版本的设备必须先卸载再安装，否则系统会拒绝覆盖。卸载会清除应用私有目录中的本地记录。
- `LightPage_1.6.0_windows-x64-setup.exe`：Windows x64 安装版，推荐普通用户使用。
- `LightPage_1.6.0_windows-x64.exe`：Windows x64 便携版，需要系统已安装 Microsoft Edge WebView2 Runtime。
- Windows 文件尚未进行代码签名，SmartScreen 可能显示安全提示。
