# 轻页 v1.6.0 发布说明

构建日期：2026-08-04

## 主要变化

- Windows 首页和命令面板新增“打开 URL”，支持通用网页、X/Twitter、YouTube 字幕和 Hacker News 评论线程。
- 网页正文转换为带 frontmatter 的本地 Markdown；图片下载到相邻的 `imgs/` 目录并改写为相对链接，随后自动加入文件库并打开。
- 快照默认保存到“文档/LightPage/url-to-markdown/域名/文章名”，重复导入以时间戳目录保留新版本。
- 增加加载、抽取、下载、校验和保存进度，以及取消、登录/CAPTCHA 交互重试、质量门禁和专项适配器回退。
- Windows 与 Android 统一升级到 1.6.0，Android `versionCode` 更新为 8。

## 浏览器依赖与隐私

- URL 导入仅支持 Windows 10/11 x64，运行时必须能找到 Google Chrome 或 Microsoft Edge；安装包不捆绑 Chromium。
- importer 作为 Windows x64 单文件 sidecar 随应用发布，终端用户无需安装 Bun 或 Node.js。
- 浏览器仅使用 LightPage 应用数据目录内的隔离 profile，不读取日常浏览器 profile；登录状态会跨导入保留，可在设置中二次确认后清除。
- 本地正文抽取未通过质量门禁时，公开页面的请求 URL 可能发送给 Defuddle 公共阅读服务作为回退；不会发送浏览器 profile、Cookie 或已抓取的正文。
- 删除文件库记录不会删除系统“文档”目录中的 Markdown、图片或历史快照。

## 已知限制

- 网站结构、反爬策略、地区限制、登录状态及字幕权限都可能影响抽取结果；交互窗口最长等待 10 分钟。
- 图片最多 64 张，单张不超过 20 MB，合计不超过 64 MB。失败图片保留远程 URL 并显示警告，视频不下载。
- YouTube 没有字幕时只保存标题、描述等可用信息并显示警告。
- 首版不支持 Android/Web URL 导入，也不捆绑浏览器。
- 超过 10 MB 的生成文档沿用源码模式打开。

## 发布产物

- `LightPage_1.6.0_windows-x64-setup.exe`：Windows x64 NSIS 安装版。
- `LightPage_1.6.0_windows-x64.exe`：Windows x64 单文件便携版，静默展开主程序、URL importer sidecar 和许可证后启动。
- `LightPage_1.6.0_android-debug.apk`：Android 调试证书签名 APK。
