## 更新内容

- Windows 支持同时打开多个阅读窗口，方便对照查看多个文件。已打开的同一路径只会聚焦已有窗口。
- 资源管理器在轻页已经运行时再次打开文件，会新建窗口并保留当前文件。进程首次启动仍由主窗口打开第一个文件。
- 命令面板「在新窗口打开文件」（`Ctrl+Shift+O`）和文件菜单「在新窗口打开...」会另开窗口。
- 目录列表和首页里有本地路径的文件提供「新窗口」。按住 Ctrl 点击 Markdown 文档链接会在新窗口打开。
- 修复资源管理器双击新建窗口后无法自动显示、任务栏也无法切换过去的问题。主窗口最小化时，新窗口不再被放到屏幕外。
- 当前窗口已打开文档时，拖入的文件分别进入新窗口；首页拖入时，第一个留在当前窗口。
- Windows 与 Android 版本统一升级到 1.6.1，Android `versionCode` 更新为 11。
- Windows 安装包仍使用 `--no-sign`。
