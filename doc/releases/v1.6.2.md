# v1.6.2

发布日期：2026-10-23。本次发布 Windows x64 安装版与便携版；Android 最新公开安装包仍为 v1.6.1。

## 更新内容

- Windows 设置新增“双击文件打开方式”，可切换“当前窗口”与“新窗口”，默认使用当前窗口。
- 当前窗口采用最近活动的阅读窗口；支持恢复最小化窗口，主窗口已关闭时仍可使用其他阅读窗口。
- 配置保存在本机，所有窗口共用，修改即时生效并在重启后保留。
- 打开队列按窗口隔离，连续打开的文件按顺序处理。
- 保留显式“在新窗口打开”、`Ctrl+Shift+O` 和 Ctrl 点击 Markdown 链接的多窗口功能。
- 设置页显示实际应用版本，Windows 与 Android 源码版本统一为 1.6.2，Android `versionCode` 更新为 12。

## 下载说明

- `LightPage_1.6.2_windows-x64-setup.exe`：Windows 10 / 11 x64 安装版，推荐普通用户使用。
- `LightPage_1.6.2_windows-x64.exe`：Windows x64 便携版，需要系统已安装 Microsoft Edge WebView2 Runtime。
- Windows 文件尚未进行代码签名，SmartScreen 可能显示安全提示。
- 本次未发布 Android 1.6.2 APK；Android 用户请继续使用 [v1.6.1 中的正式签名 APK](https://github.com/ykath/FastViewer/releases/tag/v1.6.1)。
